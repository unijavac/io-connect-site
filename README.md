# io-connect.pl

Statyczna strona produktu ioConnect6.

## Publikacja

Repozytorium GitHub Pages: `io-connect-site`.

- źródło Pages: `main` / `(root)`
- domena własna: `io-connect.pl`
- plik `CNAME` powinien zawierać `io-connect.pl`

Przycisk pobierania sprawdza przez GitHub API najnowszy Release w `unijavac/ioConnect6-App` i kieruje bezpośrednio do pliku `.apk`. Jeżeli API jest chwilowo niedostępne, przycisk prowadzi do strony najnowszego wydania.

Strona nie używa zewnętrznych fontów, trackerów ani bibliotek JavaScript.


## Wersja robocza
Ta paczka jest przeznaczona do podglądu pod adresem GitHub Pages repozytorium. Nie zawiera pliku CNAME i ma ustawienie noindex. Domena io-connect.pl nie jest podłączana na etapie testów.
